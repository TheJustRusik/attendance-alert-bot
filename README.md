# 🔔 Attendance Notify Bot

Telegram-бот, который рассылает уведомление «берут аттенданс» участникам пула предмета.
Стек: Node.js 18+, Telegraf, PostgreSQL, Redis.

## Роли
| Роль | Возможности |
|---|---|
| 👤 Пользователь | вступать/выходить из пулов, слать уведомление в пулы, где он состоит |
| 🛡 Модератор | создавать пулы, удалять **свои** пулы, удалять участников из **своих** пулов (участник получает уведомление) |
| 👑 Админ | всё выше + назначать/снимать модераторов, удалять **любые** пулы, просматривать список всех пользователей (`/users`) |

- Админы задаются через `ADMIN_IDS`, но **только если в базе нет ни одного админа**.
- Уведомление: не чаще 1 раза в `NOTIFY_COOLDOWN_SEC` (по умолчанию 10 минут) на пользователя в рамках пула. В **своём** пуле (владелец-модератор/админ) — без ограничений. Кулдаун хранится в Redis (`SET NX EX`).
- Диалоги (ввод названия пула, @username модератора) хранятся в Redis с TTL 10 минут.

## Авто-аттенданс PGE (`🤖 Авто-аттенданс в PGE` / `/autoattend`)
- Пользователь один раз привязывает аккаунт `https://pge.kbtu.kz` (бот сразу удаляет сообщения с логином и паролем из чата, проверяет вход на портале и сохраняет пару в PostgreSQL в зашифрованном виде `AES-256-GCM` с ключом `CREDENTIALS_SECRET`).
- При отправке алерта «берут аттенданс» в любой пул, где состоит пользователь с включённым авто-аттендансом, бот в фоне открывает `https://pge.kbtu.kz/RegistrationOnline`, нажимает все активные кнопки `Check in` и присылает персональный отчёт в ЛС.
- В меню `/autoattend` можно проверить и отметиться вручную в 1 клик, поставить функцию на паузу или полностью удалить свои данные из базы.

## 📊 Оценки за аттестацию Uninet (`📊 Оценки (Аттестация)` / `/attestation`)
- Просмотр оценок за 1-ю аттестацию (Рубеж 1), 2-ю аттестацию (Рубеж 2), допуск к экзамену (РД), экзамен (Финал), итоговый балл и буквенную оценку по всем предметам.
- **Работает напрямую через официальное API** (`https://uninet.kbtu.kz/api/attestation/student/me?year=&period=`) с использованием авторизации Keycloak PKCE по HTTP **без запуска браузера Playwright**, что исключает лишнюю нагрузку на сервер и обеспечивает мгновенный отклик.
- Поддерживает выбор семестров (`/api/schedule/subject/semesters`): осенний, весенний, летний.
- Автоматический вход в 1 клик для пользователей с привязанным аккаунтом KBTU (или ручной ввод с мгновенным удалением пароля из чата).

## Автопросмотр лекций Uninet (`🎬 Автопросмотр лекций в портале Uninet`)
- Доступен всем пользователям бота (не более 1 активной сессии на человека, общий лимит — `MAX_WATCH_SESSIONS`).
- Логин и пароль от портала (`https://uninet.kbtu.kz`) держатся **исключительно в оперативной памяти** на время входа (не сохраняются ни в PostgreSQL, ни в Redis), а сообщения с ними сразу удаляются из чата.
- После входа через Playwright бот показывает список доступных курсов студента (или кнопку «🚀 Все курсы подряд»), открывает материалы курса и запускает скрипт `AutoWatcher`, пересылая логи прогресса в Telegram.

## Запуск
```bash
docker compose up -d          # Postgres + Redis
cp .env.example .env          # впишите BOT_TOKEN и ADMIN_IDS
npm install
npx playwright install chromium   # (опционально, если на машине не установлен Google Chrome / Chromium)
npm start
```
Таблицы создаются автоматически при старте.

## Заметки
- Модератор должен хотя бы раз написать боту `/start`, прежде чем админ сможет его назначить.
- Если модератора разжаловать, его пулы остаются, но управлять ими сможет только админ.
- Удалённый из пула участник может вступить обратно (бана нет).
- Бот работает только в личных сообщениях.
